## **`[ 01 ] // ABOUT ME`**

### EN

I'm a Software Engineer focused on the intersection of software engineering, infrastructure and cybersecurity, with a focus on Security Engineering.

My technical background includes secure software development, REST APIs, cloud infrastructure, automation and application troubleshooting. I have also worked with security practices such as SAST, DAST, SCA, vulnerability assessment, security gates and threat modeling.

Currently pursuing an MBA in Cybersecurity at USP/ESALQ, with particular interests in Application Security, DevSecOps, Cloud Security and secure systems architecture.

**Current areas of interest:**
- Security Engineering & Application Security
- Secure SDLC & DevSecOps
- CI/CD Pipeline Security
- Cloud & Infrastructure Security
- Threat Modeling & Risk Assessment

### PT-BR

Sou Engenheira de Software, com experiência na interseção entre engenharia de software, infraestrutura e cibersegurança, e direcionamento profissional para Security Engineering.

Minha base técnica inclui desenvolvimento seguro de software, APIs REST, infraestrutura em nuvem, automação e análise e resolução de problemas em aplicações. Também tenho experiência prática com práticas de segurança como SAST, DAST, SCA, avaliação de vulnerabilidades, security gates e modelagem de ameaças.

Atualmente, curso MBA em Cibersegurança pela USP/ESALQ, com especial interesse em Application Security, DevSecOps, Cloud Security e arquitetura de sistemas seguros.

**Áreas de interesse:**
- Engenharia de Segurança e Application Security
- Secure SDLC e DevSecOps
- Segurança em pipelines CI/CD
- Segurança em nuvem e infraestrutura
- Modelagem de ameaças e gestão de riscos
